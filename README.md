# Gatepass frontend

Next.js organizer dashboard, public project/event pages, and admin dashboard. This repository contains only the frontend; its root is the Vercel project root.

Run `npm run dev` to start the app on `http://localhost:3001`. Set `NEXT_PUBLIC_API_URL` to the backend `/api` URL and `NEXT_PUBLIC_SITE_URL` to the public site origin. Production is deployed from `Goldexcool/classic-fe` at `https://gatepass.usevoii.com`.
