# Gatepass frontend

Next.js organizer dashboard, public project/event pages, and admin dashboard.

Run `npm run dev` to start the app on `http://localhost:3001`. Set `NEXT_PUBLIC_API_URL` to the backend `/api` URL and `NEXT_PUBLIC_SITE_URL` to the public site origin. See the monorepo [README](../README.md) for setup and deployment roots.
